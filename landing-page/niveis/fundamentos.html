Módulo 01

Fundamentos de IA Generativa

⏱️ 6 horas 📝 10k palavras 🎯 Iniciante

Base sólida em LLMs, transformers e conceitos essenciais de IA generativa. Entenda como funcionam os modelos de linguagem, arquitetura Transformer, tokenização, embeddings e multimodalidade.

O que você vai aprender:

  • Arquitetura Transformer e mecanismos de atenção
  • Tokenização, embeddings e representações vetoriais
  • Parâmetros de geração (temperature, top-p, top-k)
  • Modelos multimodais (texto, imagem, áudio, vídeo)
  • História e evolução dos LLMs
Começar Módulo 1
✍️
Módulo 02

Engenharia de Prompts Avançada

⏱️ 7 horas 📝 15k palavras 🎯 Iniciante-Intermediário

Técnicas avançadas: Chain-of-Thought, Self-Consistency, Tree of Thoughts, ReAct e meta-prompting. Aprenda a programar com linguagem natural.

O que você vai aprender:

  • Anatomia de um prompt perfeito (Persona, Contexto, Tarefa, Formato)
  • Zero-Shot, Few-Shot e Chain-of-Thought prompting
  • Técnicas avançadas: Self-Consistency, ToT, ReAct
  • Meta-prompting e prompt engineering sistemático
  • Debugging e otimização de prompts
Começar Módulo 2

Módulo 03

LangChain para Agentes

⏱️ 8 horas 📝 18k palavras 🎯 Intermediário

Domine LangChain: RAG, Agents, Memory, Tools e aplicações práticas completas. O framework essencial para criar agentes inteligentes.

O que você vai aprender:

  • Arquitetura e componentes do LangChain
  • RAG (Retrieval-Augmented Generation) completo
  • Agentes ReAct e sistemas de memória
  • Criação de tools customizadas
  • Chains complexas e orquestração
