Módulo 01

Fundamentos de IA Generativa

⏱️ 6 horas 📝 10k palavras 🎯 Iniciante

Base sólida em LLMs, transformers e conceitos essenciais de IA generativa. Entenda como funcionam os modelos de linguagem, arquitetura Transformer, tokenização, embeddings e multimodalidade.

O que você vai aprender:

  • O que você aprenderá:

    Entenda a arquitetura revolucionária que tornou os LLMs possíveis. Você vai dominar:

    • Self-Attention: Como o modelo "presta atenção" em diferentes partes do texto
    • Multi-Head Attention: Por que múltiplas "cabeças" de atenção são importantes
    • Encoders vs Decoders: Diferenças entre BERT, GPT e modelos encoder-decoder
    • Positional Encoding: Como o modelo entende a ordem das palavras

    💡 Exemplo prático: Você verá como o GPT decide qual palavra vem a seguir analisando todo o contexto anterior usando atenção.

  • O que você aprenderá:

    Descubra como texto vira números que a IA entende:

    • Tokenização: Como "Olá mundo" vira [42, 156] para a IA processar
    • Vocabulário: Por que GPT-4 tem 100k+ tokens e o que isso significa
    • Embeddings: Vetores de 768 ou 1536 dimensões que representam significado
    • Similaridade semântica: Como calcular que "rei" - "homem" + "mulher" ≈ "rainha"

    ⚡ Você vai fazer: Calcular embeddings de frases e medir similaridade entre conceitos usando código Python real.

  • O que você aprenderá:

    Domine os controles que mudam completamente o comportamento da IA:

    • Temperature (0.0-2.0): Controla criatividade vs consistência
      • 0.0 = Determinístico (sempre mesma resposta)
      • 0.7 = Balanceado (padrão recomendado)
      • 1.5+ = Criativo/imprevisível
    • Top-p (nucleus sampling): Limita escolhas às mais prováveis
    • Top-k: Considera apenas as k palavras mais prováveis
    • Max tokens: Limita tamanho da resposta

    🎯 Caso real: Por que chatbots usam temperature=0.7 mas código precisa de 0.0.

  • O que você aprenderá:

    Explore modelos que vão além do texto:

    • Visão + Linguagem: GPT-4 Vision, Claude 3 Sonnet analisando imagens
    • Áudio: Whisper (speech-to-text), modelos text-to-speech
    • Vídeo: Sora (OpenAI), modelos que entendem frames temporais
    • Fusion: Como diferentes modalidades são combinadas em um único modelo

    🔥 Tendência: Modelos nativamente multimodais serão o padrão. Você aprenderá a trabalhar com eles hoje.

  • O que você aprenderá:

    Entenda a jornada que nos trouxe até aqui:

    • 2017: Transformer original ("Attention is All You Need")
    • 2018: BERT e GPT-1 mudam o jogo
    • 2020: GPT-3 com 175B parâmetros choca o mundo
    • 2022: ChatGPT torna IA mainstream
    • 2023-2024: Claude 3, GPT-4, Gemini e a explosão atual
    • 2025+: Para onde estamos indo?

    📚 Contexto: Por que entender a história ajuda você a prever o futuro e tomar melhores decisões técnicas.

Módulo 02

Engenharia de Prompts Avançada

⏱️ 7 horas 📝 15k palavras 🎯 Iniciante-Intermediário

Técnicas avançadas: Chain-of-Thought, Self-Consistency, Tree of Thoughts, ReAct e meta-prompting. Aprenda a programar com linguagem natural.

O que você vai aprender:

  • O que você aprenderá:

    Domine os 4 elementos essenciais de prompts eficazes:

    • Persona: "Você é um especialista em marketing digital com 10 anos de experiência..."
    • Contexto: Forneça informações de background que a IA precisa conhecer
    • Tarefa: Instrução clara e específica do que fazer
    • Formato: Como estruturar a resposta (JSON, tabela, bullet points)

    📐 Framework: P-C-T-F (Persona-Context-Task-Format) para criar prompts profissionais consistentemente.

  • O que você aprenderá:

    • Zero-Shot: Tarefas sem exemplos - "Traduza isso para inglês"
    • Few-Shot: Fornecer 2-5 exemplos para guiar o modelo
      • Exemplo 1: Input → Output
      • Exemplo 2: Input → Output
      • Agora seu input: ?
    • Chain-of-Thought (CoT): "Pense passo a passo" para raciocínio complexo

    🎯 Caso de uso: CoT aumenta precisão em problemas matemáticos de 20% para 85%+.

  • O que você aprenderá:

    • Self-Consistency: Gerar múltiplas respostas e escolher a mais comum (voting)
    • Tree of Thoughts (ToT): Explorar múltiplos caminhos de raciocínio simultaneamente
    • ReAct (Reasoning + Acting): Combinar raciocínio com ações (usar ferramentas)
      • Thought: "Preciso buscar dados atualizados"
      • Action: search("GDP Brasil 2024")
      • Observation: "R$ 2.1 trilhões"
      • Thought: "Agora posso responder..."

    ⚡ Poder: Essas técnicas transformam LLMs em "pensadores" muito mais sofisticados.

  • O que você aprenderá:

    Meta-prompting: Usar a IA para melhorar seus próprios prompts!

    • "Analise este prompt e sugira 5 melhorias específicas"
    • "Reescreva este prompt para ser mais claro e eficaz"
    • "Identifique ambiguidades neste prompt"

    Engenharia sistemática:

    • Medir qualidade de outputs (métricas)
    • A/B testing de variações de prompts
    • Criar bibliotecas de prompts reutilizáveis
    • Versionamento e documentação

    🔧 Ferramentas: LangSmith, PromptLayer, Weights & Biases para otimização.

  • O que você aprenderá:

    Problemas comuns e soluções:

    • Output inconsistente? → Reduza temperature, seja mais específico
    • Alucinações (inventa fatos)? → Adicione "responda apenas com informações fornecidas"
    • Formato errado? → Use exemplos + validação de schema
    • Muito verboso? → "Seja conciso. Máximo 3 frases."

    Técnicas de otimização:

    • Iteração: testar → medir → ajustar → repetir
    • Simplificação: remover palavras desnecessárias
    • Constraints: limites explícitos (tamanho, tom, formato)

    📊 Métricas: Precisão, tempo de resposta, custo, consistência.

Módulo 03

LangChain para Agentes

⏱️ 8 horas 📝 18k palavras 🎯 Intermediário

Domine LangChain: RAG, Agents, Memory, Tools e aplicações práticas completas. O framework essencial para criar agentes inteligentes.

O que você vai aprender:

  • O que você aprenderá:

    Entenda a estrutura modular do LangChain:

    • Models: Interface unificada para GPT-4, Claude, Llama, etc
    • Prompts: Templates gerenciáveis e versionáveis
    • Chains: Sequências de operações (LLMChain, SequentialChain)
    • Agents: Sistemas que tomam decisões e usam ferramentas
    • Memory: Armazenamento de conversas e contexto
    • Callbacks: Hooks para logging e monitoramento

    🏗️ Arquitetura: Design modular que permite compor aplicações complexas de IA.

  • O que você aprenderá:

    Construa sistemas que respondem com seus próprios dados:

    • Document Loaders: Carregar PDFs, CSVs, websites, APIs
    • Text Splitters: Dividir documentos grandes em chunks inteligentes
    • Vector Stores: Pinecone, Chroma, FAISS para busca semântica
    • Retrievers: Buscar os documentos mais relevantes
    • Chain: Combinar retrieval + LLM para responder com contexto

    🎯 Projeto: Chatbot que responde perguntas sobre seus documentos privados com 95%+ de precisão.

  • O que você aprenderá:

    Agentes ReAct:

    • Ciclo: Observation → Thought → Action → Repeat
    • O agente decide quais tools usar dinamicamente
    • Pode encadear múltiplas ações para resolver problemas complexos

    Sistemas de Memória:

    • ConversationBufferMemory: Guardar histórico completo
    • ConversationSummaryMemory: Resumir conversas longas
    • VectorStoreMemory: Busca semântica em memórias antigas
    • EntityMemory: Lembrar fatos sobre pessoas/coisas específicas

    💡 Uso: Chatbots que lembram de conversas anteriores e mantêm contexto.

  • O que você aprenderá:

    Dar superpoderes aos seus agentes com ferramentas customizadas:

    • @tool decorator: Transformar funções Python em ferramentas LangChain
    • Descrição clara: Como o agente entende quando usar a ferramenta
    • Validação de entrada: Pydantic schemas para segurança
    • Error handling: Lidar com falhas gracefully

    Exemplos práticos:

    • Tool de cálculo avançado
    • Tool de busca em banco de dados
    • Tool de envio de emails/notificações
    • Tool de geração de gráficos

    🔧 Poder: Conectar agentes a qualquer API ou sistema que você imaginar!

  • O que você aprenderá:

    Tipos de Chains:

    • SimpleSequentialChain: Output de uma chain vira input da próxima
    • SequentialChain: Múltiplos inputs/outputs entre chains
    • RouterChain: Escolher qual chain executar baseado no input
    • MapReduceChain: Processar documentos em paralelo e combinar resultados

    Orquestração avançada:

    • Criar pipelines multi-step complexos
    • Combinar RAG + Agents + Memory
    • Paralelização para performance
    • Error recovery e retry logic

    🚀 Aplicação: Sistemas de IA de nível enterprise que orquestram múltiplas operações complexas.
