Levando Agentes de IA para o Mundo Real

Produçêo é o ambiente onde seu sistema de agentes atende usuários reais, processando dados reais, com consequências reais. Este módulo ensina você a fazer isso com excelência.

Capítulo 7.1: Fundamentos de Deploy

  • Diferenças fundamentais:

    • Escala: De 1-10 requisições/dia para 1.000-1.000.000+
    • Disponibilidade: De "pode cair" para 99.9%+ uptime
    • Dados: De testes para dados sensíveis reais
    • Custos: De mínimos para potencialmente significativos
    • Segurança: De básica para crítica
    • Monitoramento: De opcional para essencial

  • 1. Nêo-determinismo

    Mesmo input pode gerar outputs diferentes. Soluçêo: use temperature=0 para tarefas que precisam consistência.

    2. Latência Variável

    Agentes podem levar de 1s a 60s+. Requer timeouts, async processing, feedback de progresso e circuit breakers.

    3. Custos Variáveis

    Cada chamada ao LLM tem custo. Estratégias: cache, rate limiting, monitoramento de custos, fallback para modelos mais baratos.

    4. Dependências Externas

    APIs de LLMs, servidores MCP, bancos de dados, APIs de terceiros. Requer retry logic, graceful degradation, fallback strategies.

Capítulo 7.2: Containerizaçêo com Docker

    • ✓ Reprodutibilidade: Funciona igual em dev, staging e produçêo
    • ✓ Isolamento: Cada agente em seu próprio container
    • ✓ Portabilidade: Roda em qualquer cloud provider
    • ✓ Versionamento: Fácil rollback para versêo anterior

Capítulo 7.3: Deploy em Cloud

  • 1. AWS (Amazon Web Services)

    • ECS/Fargate: Container orchestration
    • Lambda: Serverless para agentes simples
    • EC2: Máquinas virtuais completas

    2. Google Cloud Platform

    • Cloud Run: Deploy de containers serverless
    • GKE: Kubernetes gerenciado
    • Vertex AI: ML/AI específico

    3. Azure

    • Container Apps: Simples e escalável
    • AKS: Kubernetes gerenciado
    • Azure Functions: Serverless

    4. Plataformas Especializadas

    • Railway.app: Deploy simplificado
    • Fly.io: Global edge deployment
    • Render: Deploy direto do GitHub

Capítulo 7.4: Monitoramento e Observabilidade

  • 1. Logs

    Registros textuais de eventos. Use structured logging (JSON) para facilitar análise.

    2. Métricas

    • Latência (p50, p95, p99)
    • Taxa de requisições (RPS)
    • Taxa de erros
    • Uso de tokens/custos

    3. Traces

    Rastreamento de requisições end-to-end. Fundamental para agentes multi-step.

    🔍 FERRAMENTAS: DataDog, New Relic, Grafana+Prometheus, Sentry, LangSmith (específico para LLMs)

    • Token Usage: Input/output tokens por requisiçêo
    • Cost per Request: Custo médio por chamada
    • Tool Call Success Rate: Taxa de sucesso de ferramentas
    • Agent Completion Rate: % de tarefas completadas com sucesso
    • Cache Hit Rate: % de respostas servidas do cache

Capítulo 7.5: Segurança em Produçêo

  • 1. Autenticaçêo e Autorizaçêo

    • API Keys com rate limiting
    • OAuth 2.0 para usuários
    • RBAC (Role-Based Access Control)

    2. Proteçêo de Dados

    • Criptografia em trânsito (TLS/HTTPS)
    • Criptografia em repouso
    • PII (Personally Identifiable Information) masking

    3. Input Validation

    • Sanitizaçêo de inputs do usuário
    • Proteçêo contra prompt injection
    • Limites de tamanho/complexidade

    4. Compliance

    • GDPR (Europa)
    • LGPD (Brasil)
    • SOC 2, ISO 27001
